# Changelog

## 1.0.0 - 2026-08-20

Initial production-oriented release containing:

- Deterministic offline Q&A and bounded knowledge base.
- Fuzzy/normalized matching with confidence thresholds.
- Safe arithmetic calculator with precedence and parentheses.
- ESP32 family-aware telemetry scaffolding and explicit availability states.
- Fast/slow/full diagnostic passes.
- Explainable health scoring.
- Optional harmless trolling mode.
- Persistent knowledge hooks through ESP32 Preferences where available.
- Arduino examples and host-side validation harness.
